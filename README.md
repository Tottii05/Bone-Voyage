# Bone Voyage

This repository contains the final project for our course, developed by a team of four students as part of our final assessment.

## 👾 About the Game

We built an **RPG Dungeon Crawler** video game using **Unity**. The player explores various themed environments, fights enemies, collects loot, and buys items to become stronger.

### Main Features:
- Real-time combat system
- Enemy pathfinding and behavior states
- Loot and inventory system
- Character progression through item purchases
- Boss fights and different enemy types
- 3D chibi-style characters
